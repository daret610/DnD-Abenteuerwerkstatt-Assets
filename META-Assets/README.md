# META-Assets

Zentrale, wiederverwendbare Stilbibliothek fuer die D&D-Abenteuerwerkstatt.

## Grundregel

Jeder One-Shot waehlt zu Projektbeginn einen verbindlichen visuellen Stil. Dieser Stil beeinflusst das gesamte Dokumentdesign sowie die verwendeten META-Assets.

META-Assets sind wiederverwendbare gestalterische Bausteine wie Banner, Verzierungen, Symbole, Rahmen, Separatoren, Kapitelmarker, Texturen, Karten-Meta-Elemente und Wappenelemente.

## Standardstruktur je Stil

```text
00_Stildefinition/
01_Banner/
02_Verzierungen/
03_Symbole_Icons/
04_Rahmen_Layout/
05_Separatoren_Linien/
06_Kapitelmarker_Labels/
07_Texturen_Hintergruende/
08_Handout_Meta/
09_Karten_Meta/
10_Fraktionen_Wappen/
```

Die Stilordner spiegeln die zentrale Google-Drive-Bibliothek logisch. GitHub verwendet robuste technische Pfade; Umlaute werden fuer URL-Stabilitaet vermieden.

Nur freigegebene, wiederverwendbare Assets werden hier veroeffentlicht. Ein separater FINAL-Unterordner ist nicht erforderlich.
