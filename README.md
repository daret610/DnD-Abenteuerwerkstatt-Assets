# DnD-Abenteuerwerkstatt-Assets

Oeffentliches Asset-Repository der D&D-Abenteuerwerkstatt.

Dieses Repository dient als technische Quelle fuer freigegebene, stabile Bild-URLs, die insbesondere in Homebrewery verwendet werden koennen.

## META-Assets

Die wiederverwendbare Stilbibliothek liegt unter `META-Assets/`.

Jeder Stil verwendet dieselbe Unterordnerstruktur. Die Arbeits- und Verwaltungsbibliothek wird in Google Drive gepflegt; dieses Repository bildet den veroeffentlichten technischen Stand ab.

Nur freigegebene, wiederverwendbare META-Assets gehoeren hier hinein. Unfertige Entwuerfe werden nicht in dieser Bibliothek abgelegt. Ein separater FINAL-Unterordner ist daher nicht vorgesehen.

Aktuelle Stilordner:

- `01_Klassich`
- `02_Horror`
- `03_Adelig`
- `04_Daemonisch`

Technische Pfade verwenden nach Moeglichkeit ASCII und vermeiden Umlaute beziehungsweise problematische Sonderzeichen.
